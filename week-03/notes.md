**How does a Windows-style file path differ from a Linux-style file path?**

```
Windows roots start with C:\ while Linux uses just uses / and is very strict on case sensitivity.

Examples: 

Windows Path C:\users\Ivy\Documents\Reports\Q3-Reports.docx

Linux Path  /home/ivy/reports/q3-reports.txt
```
